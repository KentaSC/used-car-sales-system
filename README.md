# 中古車販売Webシステム

## プロジェクト概要

職業訓練校での模擬開発プロジェクトとして、4名のチームで制作した中古車販売Webアプリケーションです。

- **開発期間：** 約2か月半
- **開発人数：** 4名
- **担当役割：** チームリーダー

中古車の検索・詳細閲覧、お気に入り登録、ユーザー認証、見積依頼などの機能を実装しました。

## ポートフォリオ資料

[ポートフォリオ（PDF）を見る](docs/portfolio_那須建太.pdf)

## 使用技術

- **フロントエンド：** HTML / CSS / JavaScript
- **バックエンド：** PHP
- **データベース：** MySQL
- **開発環境：** XAMPP

## 主な機能

- 中古車一覧・検索
- 車両詳細表示
- ユーザー登録・ログイン
- お気に入り登録
- 見積依頼

## 開発体制・担当範囲

4名のチームで開発を進め、自ら立候補しチームリーダーとしてプロジェクト全体の進行管理と仕様調整を担当しました。

**プロジェクト管理**
- WBS作成、タスク割り当て、進捗管理
- チーム内での仕様調整・意思決定
- 結合テスト、コードレビューに関する調整

**設計・実装**
- ER図の作成
- MySQLデータベースの構築
- 見積依頼機能の入力画面・確認画面の実装

## 開発で直面した課題と対応

各メンバーが個別に実装した画面を結合する際、データ項目の命名が一致せず、画面間のデータ連携に問題が発生しました。

そこで、各画面で使用する項目名や受け渡し方法を確認し、実装内容を調整することで、画面間の整合性を確保しました。

この経験から、個別機能の実装だけでなく、チーム全体で仕様を統一し、システム全体のつながりを考慮する重要性を学びました。

## 実行環境

PHPおよびMySQLが動作する環境を使用します。

データベース接続情報は `db_config.php` で管理しています。このファイルには認証情報が含まれるため、リポジトリには含めていません。

ローカル環境で実行する場合は、別途 `db_config.php` を作成し、データベース接続情報を設定する必要があります。

`db.sql` は模擬開発用のサンプルデータです。
