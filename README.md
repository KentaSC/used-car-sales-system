# 中古車販売Webシステム

## プロジェクト概要

職業訓練校での模擬開発プロジェクトとして、4名のチームで制作した中古車販売Webアプリケーションです。

- **開発期間：2か月半**
- **開発人数：4名**
- **担当役割：チームリーダー**

中古車の検索・詳細閲覧、お気に入り登録、ログイン、見積依頼などの機能を実装しました。
## ポートフォリオ資料

[ポートフォリオ（PDF）を見る](docs/portfolio.pdf)

## 使用技術

- フロントエンド：HTML / CSS / JavaScript
- バックエンド：PHP
- データベース：MySQL
- 開発環境：XAMPP

## 主な機能

- 中古車一覧・検索
- 車両詳細表示
- ユーザー登録・ログイン
- お気に入り登録
- 見積依頼

## 開発体制・担当範囲

チームリーダーとして、以下を担当しました。

- WBS作成、タスク割り当て、進捗管理
- チーム内での仕様調整・意思決定
- ER図の作成、MySQLデータベースの構築
- 見積依頼機能（入力画面・確認画面）の実装
- 結合テスト、コードレビュー、画面間のデータ連携に関する調整

## 開発で学んだこと

個別の画面や機能を実装するだけでなく、データベース設計、画面間のデータ受け渡し、チーム内での仕様統一など、システム全体の整合性を考えながら開発する重要性を学びました。

## 実行環境

PHPおよびMySQLが動作する環境を使用します。

データベース接続情報は `db_config.php` で管理しています。このファイルには認証情報が含まれるため、リポジトリには含めていません。

`db.sql` は模擬開発用のサンプルデータです。

## 補足

本リポジトリはチーム開発の成果物です。すべての機能を個人で実装したものではありません。
